## 1. Install (30 seconds)

```bash
pip install "caelum-ai[openai]"        # OpenAI
pip install "caelum-ai[anthropic]"     # Anthropic
pip install "caelum-ai[openai,anthropic,rich]"  # both, with pretty metrics
```

Python 3.10 or later. No server, no database, no account.

## 2. Change one line

```python
from caelum import OpenAI  # was: from openai import OpenAI

client = OpenAI(cache=True)  # reads OPENAI_API_KEY, like the SDK

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "How do I return an item?"}],
)
print(response.choices[0].message.content)
```

Run the same request twice: the second answer comes from the local cache, instantly and
for free.

## 4. Go further

```python
import caelum
from caelum import OpenAI

client = OpenAI(
    cache=True,
    semantic_cache=True,  # paraphrases reuse answers (sends the question to the embeddings API)
    retry=True,
)
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "How can I send back a product?"}],
)
caelum.cache_type(response)  # "exact", "semantic" or None
```

- [Caching](/caching) — exact and semantic cache.
- [Routing](/routing) — send requests to cheaper models with simple rules.
- [Reliability](/reliability) — retries and multi-provider fallback.
